四、其它支持方式

不花钱也能支持，而且同样有用：

  • 把有用的文章转发给可能需要的人
  • 在 GitHub 上给项目点个 star、提 issue 或 PR
  • 通过邮件或评论告诉我哪里写错了、哪里没讲清楚——这对我价值最大
